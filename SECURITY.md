# Security

TU Mail is a local, single-user client. It binds to 127.0.0.1 only and is not designed for public or shared hosting.

- Mailbox passwords are held in server memory for up to eight hours and are never written to disk.
- Do not expose the server to a network or put it behind a reverse proxy.

To report a vulnerability, open a private security advisory on the repository or contact the maintainer directly. Please do not file public issues for security problems.
